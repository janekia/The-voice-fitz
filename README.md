# The-voice-fitz

A professional portfolio website for The Voice Fitz, a voice actor specializing in commercials, animation, narration, and character work.

## 🌐 Live Site
👉 https://thevoicefitz.com/

## ✨ Features
- Fullscreen scrolling experience (FullPage.js)
- Embedded voice demo audio player
- Responsive design for mobile and desktop
- Contact form with Netlify integration
- SEO optimization (meta tags, Open Graph, structured data)

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- Bootstrap
- FullPage.js
- Netlify Forms

## 🎯 Purpose
This site showcases voice acting demos, services, and contact information to help clients quickly understand Fitz’s style and book projects.
